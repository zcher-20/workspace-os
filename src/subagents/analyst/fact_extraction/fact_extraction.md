## Functionality — Fact extraction

**Extract atomic facts per source.** For each document, pull the claims that matter as
structured rows: `claim / value | entity | source file | locator (page/section)`. Keep one fact
per row so they can be compared. Write this fact table to `work/facts.md` if it's large. This
table is the raw material for conflict detection — be exhaustive on the figures/dates/names that
the task cares about.
